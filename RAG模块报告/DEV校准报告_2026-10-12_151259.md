## 0. 预声明（本报告落盘于任何 DEV 评测运行之前）

### 0.1 候选策略（含支持性说明）

| 策略 | 定义 | 本轮可执行 | 说明 |

| A 纯语义 | 全部 12 条记忆参与排序，按余弦相似度取 Top3，阈值 t | ✅ | 与当前原型 `--set dev` 语义一致 |

**B 策略的无关查询口径（预声明）**：生产流程中，无关查询不会命中意图规则、不会进入语义层。因此 B 对标记为 `expect_empty` 的用例记 **n/a（未查询）**，不将其混入任何分母；A 策略正常统计无关查询。

### 0.2 阈值候选（预声明，全部比较，不提前停止）

`t ∈ {0.35, 0.40, 0.45, 0.50, 0.55}`

（依据：第三阶段原始矩阵显示相关区间约 0.327–0.615、无关查询上限约 0.420，该范围覆盖有效判别区。）

### 0.3 指标口径（预声明）

- **Recall@3** = Σ|rel∩Top3| / Σ|rel|（仅非空相关用例进入分母；无关用例 **不进入** Recall 分母）
- **Precision@3** = Σ|Top3∩(rel∪allow)| / Σ|Top3|（分母为实际越阈值条数）
- **MRR** = (Σ 1/首个 rel 名次) / 非空用例数（未命中计 0）
- **误召回率（A 策略）** = 越阈值的无关用例数 / 无关用例数（DEV 集无关用例数 = 0，见 0.5）
- **漏召回数量** = 存在 rel 未进 Top3 的用例数（按目的标签分组检查，不允许总分掩盖类别级漏召回）
- **延迟**：每条查询重复 3 次，全部样本合并，最近秩法 p50/p95（单位 ms）
- 每条查询保留：ID、原文、rel/allow/forbid、实际 Top-K 与余弦、相关性判断、误/漏召回

### 0.4 参数选择规则（预声明，先于结果）

1. **优先避免无关记忆污染上下文**：误召回为第一优先级；
2. 在误召回可接受的候选中，再比较 Recall@3、MRR、Precision@3；
3. 不允许仅凭总分会掩盖某个类别的严重漏召回（按 R/RANK/MIX 分组逐组检查）；
4. 多策略接近时，优先实现简单、易解释、易降级的方案；
5. DEV 数据不足以区分时，明确报告证据不足，**不宣布某方案已证明最优**。

### 0.5 DEV 覆盖边界（预声明）

- E01–E20 全部为**非空召回用例**（正向），**不含**无关查询、空库、重复 key、类别过滤专测——这些场景在 DEV 中**未覆盖**，不得用 TEST 数据补充校准；
- 因此「误召回率」在 DEV 上的参考价值有限（仅能通过 Precision@3 观察越阈值的组内噪声）；E21–E52 本轮**不运行**。

### 0.6 开发集过拟合风险（预声明）

同一批 20 条 DEV 查询将同时用于策略选择与阈值选择——**存在开发集过拟合风险**；TEST 集（E21–E52）保持锁定未运行，任何结论仅为"DEV 候选配置"，须经锁定的 TEST 集一次性验证后方可评估泛化性。

### 0.7 隔离与复现声明

- 运行前已核对：DEV 恰 20 条（E01–E20）、TEST 恰 32 条（E21–E52），分析脚本将显式断言"仅使用 split==dev 且 id 前缀为 E0x/E1x 的用例"；

- 本报告与配套 JSON 均为全新文件（运行前已确认路径不存在）。

## 2. DEV 候选配置与选择理由（依据 0.4 节预声明规则）

**DEV 候选配置 = 策略 B（语义 + 类别约束）× 阈值 t = 0.35**

选择过程（严格按照 0.4 节规则，未事后更改口径）：
1. **避免污染优先**：策略 B 的候选集被类别约束限定——跨类别污染在结构上不可能发生；A 策略在同等阈值下把 degree/school/language_preference 等跨类噪声排进 Top3（见 1.3 表与 A@0.35 漏召回明细：E07/E08/E11/E18 的目标全部被跨类高分项挤出）。
2. **在可接受候选中比较**：B@0.35 是唯一 Recall@3 达 95%（19/20）的组合，同时 MRR 0.675、Precision@3 61.54%——在 B 内部随阈值升高三项指标同时劣化，0.35 为预声明范围的最优点。
3. **分组核验（不掩盖类别级漏召回）**：B@0.35 按目的分组 R = 18/18、RANK = 1/2；唯一漏召回为 E10「我有什么长期目标」缺 career_goal（该记忆在本查询余弦低于 0.35，属短名词短语的模型固有弱点，与阶段三结论一致）。**未通过降低阈值到 0.35 以下来掩盖该缺陷**（0.35 已是预声明下限，不外推）。
4. **简单与降级**：B 仅比 A 多一个候选过滤条件（类别来自意图规则，现有 agent.py 已具备），实现与降级成本最低；且 B 在所有阈值上支配 A，无需简化性权衡。
5. 名称与边界：该配置称为 **DEV 候选配置**，**不构成最终验收**。

**C / D 策略：待实施（未擅自修改原型）**。最小必要修改方案（供审批）：在原型中新增 `--strategy keyword-semantic`，**直接 import 生产 `memory.py` 的真实词元打分器**（临时库、内存语料）作为关键词层，不重写打分逻辑、不改生产代码；通过后即可按同一 DEV 协议评估 C/D。
